# TajGo 1.8.4+36 — доступ администратора и международный номер

## Исправление входа

Экран входа переписывал любой ввод под `+992` и обрезал цифры. Поэтому аккаунт
с российским номером нельзя было открыть даже после назначения роли.

Теперь явно введённый международный код сохраняется. Поддерживаются полный
номер `+7`, прежний `+992` и другие номера в формате E.164; серверная политика
SMS определяет доступные страны. Девятизначный местный номер по-прежнему
относится к Таджикистану. Неполные, слишком длинные и некорректные номера
отклоняются, а не превращаются в другой номер через обрезку.

Короткая форма входа использует прокручиваемую колонку: поля остаются
смонтированными при возврате от SMS к номеру, в том числе с крупным шрифтом
и открытой клавиатурой. Сообщение Firebase о неверном номере больше не требует
исключительно таджикский формат.

## Назначение доступа

По явному запросу владельца создан аккаунт для указанного им телефона и
серверный профиль с ролью `admin`. Назначение записано в `admin_logs` вместе
с созданием профиля одним атомарным commit. Согласия с юридическими документами
и прохождение SMS от имени пользователя не имитировались. Номер, UID и
операционные квитанции не включаются в исходники приложения.

В Firebase Phone Auth сохранён список разрешённых регионов: к `TJ` добавлен
`RU`. Остальные способы входа, правила Firestore, функции, заказы и профили
других пользователей этим действием не изменялись.

Read-only проверка 16 октября в 15:05 по Москве подтвердила 45 активных функций,
шесть готовых индексов и сохранность прежних четырёх функций. По исходникам
фактически развёрнутой `ensureUserProfile` дополнительно проверено сохранение
существующей роли `admin` при первом и повторном входе. Это проверка кода,
а не вход с подменой пользователя.

## Как открыть

1. Установить APK 1.8.4+36.
2. Если показан выбор режима, нажать «Продолжить как клиент» для открытия входа.
3. Выделить предварительно заполненный `+992` и вставить свой полный номер `+7`.
4. Подтвердить вход кодом из SMS. Маршрутизация читает серверную роль и открывает
   «Управление TajGo»; отдельного пароля администратора нет.

## Проверки

- `flutter analyze` — без замечаний; полный `flutter test` — 205 тестов прошли.
- Шесть focused phone tests проверяют передачу страны без подмены, местный
  формат, недопустимый ввод, очистку поля и возврат к номеру на узком экране.
- Пять Android-тестов прошли на API 35. Настоящий Firebase SDK использует
  исключительно локальный Auth emulator: отдельный сценарий SDK — `+992`,
  экран входа, неверный/верный код и повтор — синтетический `+7`.
- Сценарии также повторно проверили native GPS, тайлы карты и привязку булавки.
- Release APK и App Bundle собраны; versionName 1.8.4, versionCode 36. Подписи
  обоих артефактов проверены и совпадают с прежним upload key TajGo. R8 mapping
  сохраняется вместе с установочными файлами.
- Подписанный release APK установлен и запущен на Android 15; за 30 секунд
  наблюдения fatal crash и необработанных исключений не обнаружено. Через
  обычную экранную форму и native key events введён синтетический номер `+7`:
  XML Android UI и снимок подтверждают сохранение всех цифр и кода страны.
  Кнопка запроса SMS не нажималась, реальных SMS и заказов проверка не создавала.

Доставка настоящих SMS оператором, физический GPS и FCM этим прогоном не
подтверждаются. Остальные условия публичного выпуска сохраняются из
[READINESS_2026_10_16.md](READINESS_2026_10_16.md).
