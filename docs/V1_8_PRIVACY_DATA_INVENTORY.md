# TajGo v1.8 — Privacy Data Inventory

Опорный документ для Google Play Data Safety, App Store Privacy и политики
конфиденциальности. Отражает фактически собираемые данные на дату Part 2.

## Таблица данных

| Данные | Собирается | Зачем | Хранение | Передача 3-м лицам | Где в коде |
|---|---|---|---|---|---|
| Номер телефона | Да (обязательно) | Вход/идентификация | До удаления аккаунта; затем обнуляется | Firebase Auth (обработчик) | `AuthService`, `users.phoneNumber` |
| Имя (displayName) | Да | Отображение, контакт по заказу | До удаления; затем обезличивается | Нет | `users.displayName` |
| Роль (customer/courier) | Да | Логика доступа | До удаления | Нет | `users.role/roles` |
| Адреса и точки доставки (A/B, текст, гео) | Да | Выполнение доставки | В заказе (обезличенно после удаления) | Курьеру заказа — точки доставки | `orders.fromLocation/toLocation`, saved addresses (P1) |
| Геолокация курьера | Да (только на линии) | Показ статуса, назначение | Пока на линии; публичная проекция без PII | Клиенту — обезличенная проекция | `TajGoLocationService`, `courier_public` |
| История заказов | Да | Операции, поддержка, споры | До 24 мес. обезличенно после удаления | Нет | `orders` |
| Токен уведомлений (FCM) | Да (при реализации FCM, P3) | Push о статусе | До logout/удаления | Firebase Messaging (обработчик) | notification tokens (P3) |
| Код получения заказа | Генерируется сервером | Подтверждение доставки | До завершения заказа; хэш, не PII | Нет; курьеру не виден | `order_secrets`, `order_customer_codes` |
| Заявка магазина | Да (при подаче) | Подключение партнёра | До решения/архива | Нет | merchant applications (P0.3) |
| Диагностика/краши | Да (при включённом Crashlytics, P3) | Стабильность | По политике Crashlytics | Firebase Crashlytics (обработчик) | `CrashReportingService` |
| Согласие с документами | Да | Юр. соответствие | До удаления | Нет | `users.legalAcceptance` |

## Принципы

- **Минимизация:** собираем только необходимое для доставки и безопасности.
- **Никакой продажи данных** третьим лицам.
- **Обезличивание при удалении** (см. `V1_8_ACCOUNT_DELETION_ARCHITECTURE.md`).
- **Код получения** хранится в закрытом виде и не виден курьеру.
- **Разрешения по требованию** (см. ниже), не при старте.

## Разрешения (permission UX)

| Разрешение | Когда запрашивается | Fallback при отказе |
|---|---|---|
| Геолокация (клиент) | При выборе «Моё местоположение» на карте | Ручной выбор адреса |
| Геолокация (курьер) | При выходе на линию | Не выходит на линию, объяснение |
| Уведомления | После pre-permission объяснения (P3) | Приложение работает без push |
| Файлы | При выборе прайса/вложения (file_selector) | Действие отменяется |
| Камера | Только при реально существующем действии | — (сейчас не используется) |

Разрешения не запрашиваются при запуске. Реализация: `TajGoLocationService`
запрашивает геолокацию лениво; `permission_handler` пока не используется в
клиентских потоках (кандидат на удаление либо на явное использование при FCM).
