# TajGo v1.8 — Two-Phone Test Plan

Проверка на двух физических Android (клиент + курьер) после owner-deploy
(Functions/Rules/indexes) и настройки Phone Auth. Требует PHONE_REQUIRED и
DEPLOY_REQUIRED.

## Подготовка (owner)
1. Deploy Functions, Rules, indexes.
2. Phone Auth: включить, добавить тестовые номера или использовать реальные SIM.
3. Назначить admin, создать тестового партнёра + товар (через админку → Functions).
4. Установить debug/pilot APK на оба телефона.

## Телефон A — клиент
- [ ] Установка, вход по SMS, роль клиента, главный экран.
- [ ] Сохранённый адрес: создать Дом (с точкой на карте и без GPS вручную).
- [ ] «Отправить посылку»: A/B, своя цена, публикация → waitingOffers.
- [ ] Получить offers от курьера, выбрать → tracking.
- [ ] Курьер на карте, статусы, код получения виден клиенту.
- [ ] Каталог: заведение → товар → корзина → оформление → tracking.
- [ ] Корзина сохраняется после рестарта приложения.
- [ ] Уведомления: включить, получить push о смене статуса (после FCM deploy).
- [ ] Профиль → Безопасность → Удаление аккаунта (не выполнять до конца тестов).

## Телефон B — курьер
- [ ] Вход по SMS, заявка курьера, admin одобряет (телефон A/admin).
- [ ] Выход на линию, GPS-статус, транспорт.
- [ ] Вкладки Рядом/Дальше: заказ 999 м доступен, 1000 м — нет.
- [ ] Предложить цену / принять, активный заказ.
- [ ] accepted → внешний навигатор к A; забрал → к B.
- [ ] Ввод кода получения (курьер код НЕ видит), завершение.
- [ ] activeOrderId очищен после завершения.

## Admin (телефон/веб)
- [ ] Заявка магазина: подать (клиент) → admin review → approve → convert → publish.
- [ ] Импорт CSV/XLSX: выбрать партнёра, файл, dry-run, запись.
- [ ] Заказы, курьеры, диспетчер-карта, audit logs.
- [ ] forceOffline курьера.

## Сбои (устойчивость)
- [ ] Сеть off 30 сек во время заказа → восстановление.
- [ ] Рестарт приложения на активном заказе.
- [ ] GPS denied / off / stale — понятные сообщения, ручной fallback.
- [ ] Двойной тап «Опубликовать»/«Выбрать» — один результат (идемпотентность).
- [ ] Два курьера на один заказ / два клиента на одного курьера — один выигрывает.
- [ ] Изменение цены каталога во время оформления → price-changed → повтор.
- [ ] Навигатор не установлен → fallback.
- [ ] Уведомления запрещены → приложение работает.

## Критерий
Все чек-боксы пройдены на двух устройствах без потери данных, дублей заказов и
утечки кода/телефона. Технические ошибки пользователю не показываются.
