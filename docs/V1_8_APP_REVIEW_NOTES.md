# TajGo v1.8 — App Review Notes (для ревьюеров Google Play / App Store)

## О приложении
TajGo — сервис городской доставки в Худжанде (Таджикистан). Пилотный режим.
Основные сценарии: отправка посылки со своей ценой, заказ еды/продуктов/цветов,
режим курьера, подключение магазина.

## Тестовый доступ
- Вход по номеру телефона (SMS). Для ревью настроены **тестовые номера** в
  Firebase Phone Auth (owner добавляет в Console: номер + фиксированный код).
- Тестовый номер клиента: `+992 XX XXX XX XX`, код `______` (заполнить owner).
- Тестовый номер курьера: `+992 XX XXX XX XX`, код `______` (заполнить owner).

## Роли
- **Клиент** (по умолчанию): создаёт доставки, заказывает из каталога, отслеживает.
- **Курьер**: активируется через заявку с одобрением администратора («Зарабатывать
  с TajGo» в профиле). Для ревью можно заранее одобрить тестовый номер курьера.
- **Admin**: серверная роль, назначается владельцем; ревьюеру недоступна и не
  нужна. Обычные пользователи админку не видят.

## Что проверить
1. Вход по тестовому номеру → главный экран.
2. «Отправить посылку»: точки A/B на карте, своя цена, публикация, ожидание
   предложений.
3. Каталог: Еда/Продукты/Цветы → заведение → товар → корзина → оформление.
4. Профиль → Безопасность и данные → **Удаление аккаунта** (in-app flow).
5. Настройки → Уведомления (pre-permission).

## Разрешения
- Геолокация — только при выборе точки/выходе курьера на линию (не при старте).
- Уведомления — по запросу из настроек.

## Приватность
- Удаление аккаунта: in-app и по URL (deletion URL). Данные обезличиваются.
- Код получения заказа не виден курьеру.
- Privacy policy URL и deletion URL — в листинге.

## Примечания
- Оплата на этапе пилота — вне приложения; финансовые данные не собираются.
- Preview/демо-данные каталога помечены и не оформляются.
