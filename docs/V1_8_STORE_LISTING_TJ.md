# TajGo — Store Listing (Тоҷикӣ, черновик)

Черновик на таджикском; проверить у носителя языка перед публикацией.

## Ном
TajGo — расонидани Хуҷанд

## Тавсифи кӯтоҳ (то 80 аломат)
Расонидан дар Хуҷанд: посылка бо нархи худ, хӯрок, маҳсулот ва гулҳо.

## Тавсифи пурра
TajGo — хидмати расонидани шаҳрӣ дар Хуҷанд.

• Фиристодани посылка — аз куҷо ва ба куҷо нишон диҳед, нархи худро таъин кунед.
  Курьерҳо шартҳо пешниҳод мекунанд, шумо интихоб мекунед.
• Хӯрок, маҳсулот ва гулҳо — аз ҷойҳои санҷидашудаи шаҳр.
• Пайгирӣ дар вақти воқеӣ — курьер дар харита, ҳолати фармоиш, коди гирифтан.
• Суроғаҳои қулай — Хона, Кор ва суроғаҳои дигар.
• Бехатарӣ — коди гирифтан ба курьер намоён нест.

Шумо метавонед курьер шавед ё мағозаи худро пайваст кунед — бевосита дар барнома.

Нархҳо бо сомонӣ. Хидмат дар ҳолати озмоишӣ (пилот) дар Хуҷанд кор мекунад.
